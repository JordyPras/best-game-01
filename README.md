Emberhold is an original top-down arena shooter: 10 waves, 5 enemy types plus a boss, upgrades, dash and combo scoring — canvas 2D, zero libraries, synthesized audio.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

Then open out/game/index.html in a desktop browser.
